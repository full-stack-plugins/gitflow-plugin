# GitFlow v0.1.1

GitFlow 加入 Full Stack Plugins 市场，提供固定版本的 Codex、ZCode 与 Kimi 清单，以及体现分支汇合的透明 logo。

- 官方 Git 橙色标志由 Jason Long 创作；衍生图像按 CC BY 3.0 署名。完整来源、许可与修改说明见 assets/README.md。
- 三端市场安装来源与远程图像均固定到 v0.1.1，不随 main 漂移。
- 新增 Kimi 九技能和 stdio MCP 清单；CLI/MCP 版本同步为 0.1.1。原有 Git 操作策略不变。

本次本地验证：包校验和 90 个快照文件摘要通过；打包与隔离安装测试 4/4、MCP/Hook 协议测试 17/17、市场回归测试 3/3 通过；根 manifest 通过 Agent Plugins 1.0.0 官方 Schema。图像为 1254 × 1254 RGBA PNG，已检查真实透明边缘。

市场回归测试在临时目录使用 UI Design 已发布 v0.1.1 检出，避免修改用户工作区中其他插件。市场对 GitFlow 的单项清单校验通过。GitHub Actions 结果以实际远端运行状态为准。

验证边界：未执行三宿主实际安装加载、Kimi 事件 Hook 接线、托管分支保护或生产验收；源码发布、离线协议重放及市场结构校验不代替这些验证。
