# GitFlow v0.1.3

自动 Hook 仅在真实 Git 工作树中触发。普通目录与 bare 仓库保持静默，缺少宿主 cwd 不再误用插件所在仓库；手动 CLI/MCP discover、context、init 保留接入功能。

- 使用只读 rev-parse 判断工作树，支持 unborn、detached、子目录、linked worktree 与子模块。
- git -C、紧凑 -Cpath 与简单 cd 链按实际目标检测；逐事件重新发现，初始化后启用、取消管理后停用。
- 无 Git 不注入上下文、不生成初始化问题、不写入项目或 PLUGIN_DATA；损坏/不可读 Git 返回未验证。
- 新增 12 项项目触发测试并扩充解包异 cwd 回归；完整 81 项测试本地通过，包与技能锁校验通过。Linux/macOS CI 绑定发布源码提交，运行状态见 GitHub Actions。

限制：Hook 由真实子进程重放验证；没有执行宿主安装。技能/MCP 是否预加载及实际事件接线由宿主控制，不能据此宣称所有客户端已完成安装验收。任意脚本、动态 shell 和复杂控制流的全部 Git 行为仍不在当前静态解析保证范围内。
