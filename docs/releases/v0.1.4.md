# GitFlow v0.1.4

包含 v0.1.3 的 Git 项目检测：自动 Hook 只在真实 Git 工作树中触发；无 Git、bare、缺失 cwd 保持静默，支持子目录、worktree、子模块及实际 -C/cd 目标，保留显式接入命令。

v0.1.3 的远端全量测试暴露 Python 3.11 原生 Hook 参数解析失败，macOS/Python 3.13 同一套 81 项通过。本补丁改用 parse_intermixed_args，修复 commit-msg/pre-push 的 -- 边界，不移动旧 tag 或覆盖旧发行资产。

完整本地回归 81 项通过，技能锁与包验证通过；Linux/Python 3.11 和 macOS/Python 3.13 的远端结果以本 tag 对应源码 commit 的 Actions 为准。宿主安装与事件接线未执行，Hook 协议重放不代表所有客户端已完成宿主验收。
