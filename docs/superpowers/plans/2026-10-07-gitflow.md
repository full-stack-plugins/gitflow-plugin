# GitFlow Implementation Plan

> 延续现有规格与执行计划，增量采用 TDD 与 verification-before-completion。首版仅本地交付；后续已有用户提交、推送和发行授权。

**Goal:** 实现九技能与项目 Git 分支治理插件。
**Architecture:** 技能与运行时来源独立；gitflow 工具负责发现、规范、审计、操作、Hooks/MCP；共享定义与 Git 生效快照分层。
**Tech Stack:** Python 3.11+ 标准库、Git 2.41+。
**Spec:** ../specs/2026-10-07-gitflow.md

## Global Constraints

- 对应 R01–R21，不以文档或局部测试代替实现。
- 不安装依赖、不初始化规格工具、不创建开发分支；仅发布已授权的当前变更。
- runtime 无 shell；写操作显式 apply；保护 dirty 与现有规范。

## Review Focus

- linked worktree 与父仓库误判；规范自修改弱化；复合 Git 命令归属；远端超时但副作用已发生；浅历史与初始空仓。
